# Skill Nexis - Week 2: Creating a Small Language Model

A small character-level neural bigram language model that learns character transitions from a synthetic name corpus and generates new names from a starter character or sequence.

## What is included

- `mini_project.py` - the single Python entry point. It creates/loads the dataset, builds the vocabulary, encodes/decodes characters, trains the model, evaluates losses, and generates names.
- `data/names.txt` - the prepared corpus containing 6,000 synthetic names.
- `data/DATASET_LICENSE.txt` - CC0 1.0 dedication for the original educational dataset.
- `artifacts/bigram_char_model.pt` - trained PyTorch checkpoint, including the model parameters and character vocabulary.
- `results/training_metrics.csv` and `results/training_metrics.json` - recorded training and validation loss values.
- `results/loss_curve.png` - training/validation loss plot.
- `results/generated_samples.txt` - ten samples from the randomly initialized model and ten samples from the trained model.
- `Assignment_Answers.docx` - written assignment report and mini-project explanation.
- `requirements.txt` - Python dependencies.

## Model summary

The model is a character-level bigram neural network. Each character ID is passed through an embedding table that produces a probability distribution over the next character. It therefore learns the next-character distribution conditioned on the current character.

| Item | Value |
|---|---:|
| Dataset | Skill Nexis Open Name Corpus (CC0) |
| Total examples | 6,000 names |
| Training / validation split | 5,400 / 600 (90% / 10%) |
| Vocabulary size | 42 characters (including line break) |
| Training iterations | 1,800 |
| Batch size | 256 |
| Learning rate | 0.025 |
| Initial training loss | 4.2767 |
| Final training loss | 1.8626 |
| Initial validation loss | 4.2890 |
| Final validation loss | 1.8668 |

The validation loss is close to the training loss, indicating that the model learned character-level patterns that also occur in the held-out names. The model is intentionally small and does not understand meaning or long-range structure.

## Dataset and licensing

The included dataset is an original synthetic educational corpus. Names were generated by combining syllable-like prefixes, middle units, and suffixes. The dataset is released under the **CC0 1.0 Universal** public-domain dedication; see `data/DATASET_LICENSE.txt`. It is not a list of real people's names and is not copied from a third-party name database.

## Learning notes

- **Character vocabulary:** the set of unique characters observed in the corpus.
- **Encoding/decoding:** maps characters to integer token IDs and maps IDs back to characters.
- **Bigram prediction:** predicts the next character using only the current character as context.
- **Loss:** cross-entropy measures how well the predicted next-character distribution matches the actual next character; lower is better.
- **Self-attention:** a mechanism used in Transformer models that lets each token weigh information from other positions in a sequence. This mini-project does not implement self-attention; it is included as a conceptual topic in the report.

## Run environment

Python 3.10+ and PyTorch 2.0+ are recommended. The included checkpoint was generated with PyTorch in the build environment. Model inference is local and does not call an external API.
